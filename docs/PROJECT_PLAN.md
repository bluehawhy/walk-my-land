# 걸어서내땅 · WalkMyLand

> 내가 걷는 길이 내 땅이 된다.

프로젝트 기획서 v0.2 · 작성일 2026-11-18 (한국 시간)

## 1. 프로젝트 이름

| 항목 | 확정 명칭 |
|---|---|
| 서비스명 | 걸어서내땅 |
| 영문명 | WalkMyLand |
| 저장소·프로젝트 식별자 | `walk-my-land` |
| 한 줄 소개 | 평소 걷는 길에서 영토를 모으고, 어디서든 내 땅을 가꾸는 지도 기반 게임 |
| 슬로건 | 내가 걷는 길이 내 땅이 된다 |

‘걸어서내땅’은 걷는 길이 내 영역으로 바뀌는 게임의 핵심을 담는다. 영문명 WalkMyLand는 Walk + My Land를 결합한 이름으로 확정했다. 영문 슬로건은 “Every step makes it yours.”이다. 서비스명 중복·도메인·상표 사용 가능 여부는 확인하지 않았다.

저장소: https://github.com/bluehawhy/walk-my-land

## 2. 방향과 결정 상태

**핵심 방향: 걷기로 영토를 넓히고, 집에서도 영토를 관리한다.**

| 구분 | 내용 |
|---|---|
| 사용자 지정 | OpenFreeMap + OpenStreetMap 기반 지도, 실제 걷기 중심 |
| 해결할 문제 | 플레이하려고 계속 이동해야 하는 피로, 방어 때문에 재방문해야 하는 부담 |
| 이번 문서의 설계안 | 육각형 영토, 재방문 보상, 원격 관리·공격, 짧은 산책 중심 보상 |
| 미정 | 출시 플랫폼, 서버 구성, 최종 수치, 수익화, 시즌 길이 |

이하 규칙과 수치는 개발 검토를 위한 초안이다. 구현 완료나 사용자 최종 확정을 의미하지 않는다.

## 3. 경험 목표

- 하루 5~10분 정도의 짧은 산책에도 눈에 보이는 성장을 제공한다.
- 출퇴근·등하교·동네 산책처럼 같은 경로를 반복해도 보상을 얻는다.
- 접속하지 않은 동안 공격받아도 누적 탐험 기록과 계정 성장은 잃지 않는다.
- 더 오래 걷는 행동은 탐험 기록에 보상하되, 전투력 증가에는 일일 상한을 둔다.
- 잠깐 쉬었다 돌아와도 다시 참여하기 쉽도록 한다.

초기 이용 흐름 예시: 산책 시작 → 주변 빈 구역 점령 → 익숙한 길에서 순찰 보상 획득 → 산책 종료 → 집에서 영토 강화 또는 공격 → 오늘의 탐험 기록 확인.

## 4. 지도 구성

| 구성 | 역할 |
|---|---|
| OpenStreetMap | 실제 도로·건물·지형 등의 지도 데이터 기반 |
| OpenFreeMap | 배경 지도의 타일·스타일 제공 |
| 지도 렌더러 | 플랫폼에 맞게 지도 표시와 조작을 담당; MapLibre 계열을 우선 검토 |
| 게임 영토 레이어 | 지도 위에 독립적인 셀과 소유권·방어 상태 표시 |
| 게임 서버 | 영토 소유권, 행동력, 전투, 보상 최종 판정 |

OpenFreeMap 공식 가이드는 MapLibre를 통한 웹 지도 표시와 모바일용 MapLibre Native 사용을 안내한다.[1] 지도 표시와 게임 규칙은 분리한다. 지도 데이터에 게임 소유권을 쓰지 않으며, OSM 건물·토지 경계를 실제 소유권으로 취급하지 않는다.

배경은 연한 색으로 표현하고, 내 영토는 초록·다른 이용자 영토는 보라·중립은 얇은 테두리로 구분한다. 아이콘과 테두리도 함께 사용한다. 출처 표시는 기본 지도 구성에서 유지하고 UI에 가려지지 않게 배치한다.

### 영토 단위

- 고정된 육각형 셀을 기본안으로 삼는다. 동일한 위치는 항상 같은 셀 ID에 대응한다.
- 셀 크기는 지도 화면의 픽셀 크기와 무관하게 고정한다.
- 초기 목표는 대략 100m 안팎의 셀 폭이며, 실제 격자 체계와 해상도를 정할 때 조정한다.
- 점령은 셀 중심 방문이 아니라, 허용된 셀 내부에서 유효한 위치가 확인되는 방식으로 설계한다.
- 바다·출입 제한 지역 등은 점령 대상에서 제외할 수 있도록 별도 운영 마스크를 둔다. 지도 속성만으로 접근 가능 여부가 완전하게 보장된다고 가정하지 않는다.
- 기존 영토와 떨어진 동네에서도 직접 방문하면 중립 구역을 점령할 수 있다. 연결 보너스는 후속 검토 사항이다.

## 5. 걷기와 점령

### 산책 시작

이용자가 ‘산책 시작’을 누르면 위치 확인을 시작한다. 위치 권한을 허용하지 않아도 지도 탐색과 기존 영토 관리는 가능하게 한다. 신규 점령과 걷기 보상에는 위치 확인이 필요하다.

MVP는 앱을 화면에 켠 상태에서의 산책을 대상으로 한다. 화면 잠금·백그라운드에서도 자동 적립되는 기능은 별도 범위로 둔다. 짧은 산책 목표와 별개로, 화면을 계속 켜야 하는 부담은 실기기 검토가 필요하다.

### 중립 구역 점령

1. 점령 가능한 셀에 들어오면 위치 정확도와 일정 시간의 체류를 확인한다.
2. 서버가 유효한 방문·현재 소유권·점령 비용을 확인한다.
3. 조건을 만족하면 자동 점령하고 산책 기록에 추가한다.
4. 이동 중 세밀한 조작을 요구하지 않고, 결과는 산책 종료 시 모아 보여준다.

초기 자동 점령은 중립 셀만 대상으로 한다. 상대 영토에 들어왔다고 자동으로 공격하거나 행동력을 소비하지 않는다. 동시에 같은 땅을 점령하면 서버에서 먼저 승인된 요청을 적용하고, 실패한 요청에는 비용을 차감하지 않는다.

### 같은 길 재방문

| 방문 대상 | 처리안 |
|---|---|
| 중립 구역 | 최초 점령 및 탐험 기록 |
| 내 영토 | 순찰 보상 획득, 방어 보충 기회 제공 |
| 다른 이용자의 영토 | 소유권을 바꾸지 않고 방문 보상 획득, 공격은 별도 선택 |
| 오늘 이미 보상받은 셀 | 방문 기록은 남기되 전투 자원 중복 지급 제한 |

남의 땅으로 가득 찬 동네에서도 산책 보상을 얻을 수 있어야 한다. 동일 셀의 방문 보상은 일일 1회로 시작하며, 재방문·신규 방문 모두 같은 일일 전투 자원 한도를 공유한다.

## 6. 집에서도 가능한 관리

| 행동 | 현장 방문 | 설계안 |
|---|---|---|
| 중립 구역 최초 점령 | 필요 | 직접 방문한 셀만 점령 |
| 기존 영토 강화 | 불필요 | 자원을 소비해 방어력 향상 |
| 영토 보상 수령 | 불필요 | 전체 영토를 한 번에 정산 |
| 다른 이용자의 영토 공격 | 불필요 | 방문으로 확보한 공격 가능 구역에 한해 허용 |
| 현장 공격 | 필요 | 원격 공격보다 행동력 비용 할인 |
| 누적 탐험·성장 확인 | 불필요 | 땅을 잃어도 기록 유지 |

원격 공격은 처음부터 지도 어디든 가능한 방식으로 열지 않는다. **이번 시즌에 직접 방문한 적이 있는 셀**만 공격 대상으로 등록하는 안을 사용한다. 상대 영토를 방문해도 보상과 공격 기회를 얻기 때문에 혼잡한 지역에서도 활동할 수 있다. 중립 셀로 바뀐 곳의 원격 신규 점령은 허용하지 않는다.

## 7. 전투와 패배 부담 완화

MVP 전투는 캐릭터 전투 없이 ‘공격 실행 → 방어력 감소 → 0이 되면 소유권 변경’으로 단순화한다. 공격·강화·소유권 변경은 서버가 순서대로 처리한다.

- 공격에는 행동력을 사용한다. 실패·중복 요청으로 행동력이 이중 차감되지 않게 한다.
- 구역 방어력과 강화 단계에는 상한을 둔다.
- 방어력 0으로 점령되면 새 소유자의 초기 방어력으로 재설정한다. 상대가 투자한 강화 전부를 그대로 승계하지 않는 안으로 시작한다.
- 점령 직후 짧은 보호 시간을 적용해 즉시 반복 탈취를 줄인다.
- 공격받았다는 이유로 현장 복귀를 요구하지 않는다. 원격 보강과 이후 재도전이 가능하다.
- 잃는 것은 현재 영토 소유권이다. 이미 획득한 탐험 기록·계정 경험치·확정 시즌 점수는 보존한다.
- 알림은 기본적으로 요약해서 제공하고, 실시간 방어 대응을 강제하지 않는다.

## 8. 성장과 보상

| 항목 | 획득 | 사용·의미 |
|---|---|---|
| 행동력 | 기본 회복 + 유효한 산책 보너스 | 점령·공격 |
| 관리 자원 | 일일 산책·순찰·영토 정산 | 영토 강화 |
| 탐험 경험치 | 유효한 신규·재방문 활동 | 영구 계정 성장; 초기에는 기록·꾸미기 중심 |
| 시즌 점수 | 일일 활동 + 제한된 영토 보유 점수 | 시즌 순위 |

행동력에는 기본 회복과 산책 보너스를 모두 두어 하루 쉬었다고 관리가 완전히 멈추지 않게 한다. 다만 기본 회복만으로 새로운 지역을 원격 개척할 수는 없다.

영토를 많이 보유할수록 무제한으로 강해지는 구조를 막기 위해 자원 생산량과 전투용 산책 보상에 일일 상한을 둔다. 상한 이후에도 탐험 경로·배지·방문 기록은 쌓일 수 있다. 순위 점수 역시 단순한 총 이동 거리 경쟁으로 만들지 않는다.

### 초기 조정값 후보

| 항목 | 초안 | 목적 |
|---|---|---|
| 주요 일일 활동 목표 | 유효 방문 3개 셀 | 짧은 생활 이동에도 달성 가능하도록 검토 |
| 기대 산책 시간 | 약 5~10분 | 성능·환경에 따른 보장 시간이 아닌 경험 목표 |
| 유효 체류 | 동일 셀 내 약 10~20초 | 일시적인 위치 튐으로 인한 점령 완화 |
| 셀별 방문 보상 | 하루 1회 | 제자리 반복 보상 방지 |
| 행동력 최대 보유 | 100 | 장기 축적으로 인한 격차 완화 |
| 기본 회복 | 시간당 5 | 쉬는 날에도 일부 관리·공격 가능 |
| 산책 보너스 | 보상 대상 셀당 10, 하루 최대 30 | 짧은 산책을 전투 자원 보상에 연결 |
| 중립 점령 비용 | 5 | 작은 활동으로도 점령 가능 |
| 원격 공격 비용 | 회당 20 | 반복 공격 제한 |
| 현장 공격 비용 | 회당 15 | 재방문에 가벼운 이점 제공 |
| 점령 후 보호 | 2시간 | 즉시 재탈취 반복 완화 |
| 시즌 길이 | 2주 후보 | 초기 운영 부담과 경쟁 주기 조정 |

셀 점령 횟수, 하루 공격 횟수, 공격 피해량, 최대 방어력, 영토 생산 상한은 함께 조정해야 한다. 위 숫자만으로 전투 밸런스가 완성된 것은 아니다. 일일 경계는 초기 한국 서비스 기준 오전 0시로 통일하고 서버 시간으로 계산한다.

## 9. 시즌과 재참여

시즌은 경쟁 영토를 주기적으로 초기화하고 탐험 기록은 남기는 방향으로 제안한다. 첫 MVP에는 시즌 식별자와 점수 집계를 마련하고, 실제 자동 초기화와 보상 지급은 후속 단계에서 적용한다.

| 시즌 종료 시 초기화 후보 | 유지 |
|---|---|
| 영토 소유권·방어 단계 | 계정·닉네임 |
| 시즌 점수·순위 | 누적 탐험 기록·배지 |
| 방문 기반 공격 가능 셀 목록 | 영구 경험치·꾸미기 |

행동력과 관리 자원의 이월 여부는 미정이다. 시즌 운영을 시작하기 전에 초기화 시점, 정산 중 공격 처리, 보상 기준, 이월 규칙을 확정한다.

## 10. 화면 구성

| 화면 | 핵심 내용 |
|---|---|
| 메인 지도 | 내 위치, 영토 상태, 행동력, 산책 시작·종료 |
| 산책 결과 | 점령한 셀, 재방문 수, 획득 자원, 오늘의 목표 진행 |
| 영토 상세 | 소유자, 방어력, 보호 시간, 강화·공격 버튼 |
| 내 영토 | 보유 목록, 일괄 정산, 원격 강화 |
| 탐험 기록 | 누적 방문 셀, 활동일, 배지 |
| 시즌 순위 | 시즌 기간, 내 점수, 순위와 점수 기준 |

이동 중에는 지도와 간단한 상태만 보여준다. 영토 상세는 하단 시트로 열고, 지도 탐색을 계속할 수 있도록 한다. GPS 신호가 불안정하면 ‘위치 확인 중’으로 표시하며 확정되지 않은 점령을 완료 상태로 보이지 않게 한다.

## 11. 구현 구조 초안

출시 플랫폼은 아직 선택하지 않는다. 우선 실기기에서 지도와 위치 확인을 검증한 뒤 웹·앱·미니앱 범위를 결정한다. 특정 플랫폼에서 백그라운드 위치 수집이 가능하다고 전제하지 않는다.

| 영역 | 책임 |
|---|---|
| 클라이언트 | 지도, 위치 권한, 산책 세션, 영토 UI, 서버 결과 반영 |
| 서버 | 위치·활동 판정, 점령·전투, 보상·중복 방지, 시즌 집계 |
| 데이터 저장소 | 계정, 셀 상태, 방문 이력, 자원 원장, 전투 이력 |
| 운영 설정 | 격자 규격, 비용·상한·보호 시간, 제외 구역, 시즌 상태 |

최소 데이터 개체는 `users`, `territory_cells`, `walk_sessions`, `cell_visits`, `resource_ledger`, `battle_events`, `seasons`로 제안한다. 영토 셀은 시즌 ID와 셀 ID로 유일하게 식별하고, 소유권 변경 버전을 둬 동시 공격을 처리한다. 방문 보상은 사용자·셀·기준일 조합으로 중복 지급을 방지한다.

### 위치 데이터와 판정

- GPS 정확도·시간·이동 연속성을 함께 보고, 단일 좌표만으로 즉시 보상을 확정하지 않는다.
- 차량 이동으로 의심되는 구간은 걷기 보상 판정에서 분리하되, 단순 속도 임계값 하나만으로 계정을 제재하지 않는다.
- 위치 위조를 완전히 차단할 수 있다고 가정하지 않는다. 의심 활동에는 보상 보류와 검토 가능한 기록을 둔다.
- 공개 지도에 다른 사용자의 실시간 위치·정확한 이동 경로는 표시하지 않는다.
- 소유 셀에서도 생활권이 추정될 수 있으므로 공개 프로필의 전체 영토 모아보기는 초기 제외한다.
- 원시 좌표의 수집 항목·보관 기간·삭제 정책은 출시 전 결정한다. 영구 성장 기록에는 가능한 한 셀 단위 집계를 사용한다.
- 연결이 끊기면 점령은 대기 상태로 표시한다. MVP에서 오프라인 점령 확정과 무제한 소급 보상을 제공하지 않는다.

## 12. 구현 범위와 순서

| 단계 | 포함 범위 | 완료 판단 |
|---|---|---|
| 1. 지도·걷기 검토 | 지도 표시, 격자, 내 위치, 산책 세션 | 실기기에서 셀 통과와 위치 오차를 관찰할 수 있음 |
| 2. 점령·관리 MVP | 중립 점령, 재방문 보상, 행동력, 원격 강화·정산 | 짧은 산책 후 집에서 관리하는 흐름이 이어짐 |
| 3. 경쟁 MVP | 방문 셀 원격 공격, 보호 시간, 소유권 변경 | 동시 요청에도 비용과 소유권이 일관됨 |
| 4. 시즌 운영 | 점수·순위, 초기화, 시즌 보상 | 초기화와 영구 성장 보존 규칙이 명확함 |

초기 제외: 길드·연합전, 실시간 협동전, 랜드마크 공성전, 3D 캐릭터 전투, 백그라운드 자동 산책, 현금성 보상, 거래 기능. 수익화와 광고는 핵심 산책·관리 경험을 확인한 뒤 별도로 설계한다.

## 13. 사용자 경험 검토 항목

이 절은 기획 검토 기준이며 테스트 코드 작성이나 실행 요청을 포함하지 않는다.

- 같은 출퇴근길을 며칠 반복해도 성장할 수 있는가?
- 주변이 타인 영토뿐이어도 보상과 공격 기회를 얻을 수 있는가?
- 짧은 산책으로 주요 일일 보상을 얻고, 장시간 이동에 과도한 전투 이점이 생기지 않는가?
- 하루 쉬거나 영토를 모두 잃어도 재참여가 가능한가?
- GPS 오차로 도로 반대편이나 접근할 수 없는 셀을 방문한 것으로 판정하지 않는가?
- 산책 중 화면 확인 횟수, 배터리 사용, 위치 정확도의 균형이 적절한가?

## 14. 다음 결정 사항

우선 결정할 것은 출시 플랫폼과 실제 산책 시 셀 크기다. 이후 원격 공격의 범위, 전투 수치, 시즌 초기화 규칙을 순서대로 확정한다. 문서의 기본 원칙은 **가까운 곳을 조금 걸어도 진전이 있고, 쉬는 시간에도 내 땅을 관리할 수 있어야 한다**는 것이다.
