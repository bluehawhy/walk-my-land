# 걸어서내땅 · WalkMyLand

> 내가 걷는 길이 내 땅이 된다.  
> Every step makes it yours.

걸어서 땅을 넓히고, 어디서든 내 영역을 가꾸는 지도 기반 게임입니다.

## 프로젝트 명칭

| 구분 | 명칭 |
|---|---|
| 한글 앱 이름 | 걸어서내땅 |
| 영어 이름·코드 명칭 | WalkMyLand |
| 저장소·프로젝트 ID | `walk-my-land` |

## 핵심 방향

- OpenFreeMap + OpenStreetMap 기반의 실제 지도를 사용합니다.
- 직접 걸으며 도로로 둘러싸인 블록을 점령합니다. 블록 하나가 땅 하나입니다.
- 같은 길을 다시 걸어도 순찰·방문 보상을 얻습니다.
- 영토 강화와 보상 수령은 어디서든 가능합니다.
- 짧은 산책에도 성장할 수 있고, 땅을 잃어도 누적 탐험 기록은 유지합니다.

## 기획 문서

[프로젝트 기획서](PROJECT_PLAN.md)에 지도 구성, 점령·전투 규칙, 보상, 화면 구성, MVP 범위를 정리했습니다.

## 현재 상태

프로젝트 이름과 기본 방향을 확정한 기획 단계입니다. 앱·서버 구현은 아직 시작하지 않았습니다.

출시 플랫폼, 기술 스택, 도로 블록 생성 규칙, 전투 수치, 시즌 정책은 추후 확정합니다. 기획서의 세부 수치는 조정 가능한 초안입니다.

## 개발 순서

1. 지도 표시·도로 블록·위치 확인과 산책 흐름 검토
2. 점령·재방문 보상·원격 관리
3. 방문한 구역에 대한 원격 공격과 보호 시간
4. 시즌 점수·순위·초기화
